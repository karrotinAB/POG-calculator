이후 원하는 매장의 pog.artbox.kr 페이지에서 클릭하면 데이터가 전송됩니다
  1. 위 버튼을 즐겨찾기 바에 드래그해서 저장 (최초 1회만)
  2. pog.artbox.kr 접속 후 로그인 → 원하는 매장 페이지로 이동
  3. 저장한 즐겨찾기 클릭 → 매대 데이터가 이 페이지로 전송됨
  4. 이전에 작업한 매장이면 진열방식이 자동으로 복원됩니다
